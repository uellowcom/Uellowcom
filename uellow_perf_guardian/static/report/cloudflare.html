Uellow — Performance & Cloudflare Hardening Report

29 يونيو 2026

① الملخّص التنفيذي

كان التطبيق والموقع يعانيان من بطء وتعليق متقطّع، وكان تاب الريلز لا يعرض الفيديوهات. بعد التشخيص تبيّن سببان رئيسيان:

  • التطبيق: نقاط نهاية قوائم المنتجات كانت تجلب الكتالوج كامل (~3,500 منتج) في كل طلب بدون حدّ SQL، فيقوم Odoo بعمل prefetch لكل الأعمدة عبر كل الصفوف — يستهلك الـworkers.
  • الموقع: زحف bots كثيف على روابط /shop المفلترة (مساحة فلاتر شبه لا نهائية)، كل طلب عرض كامل 1–2 ثانية وعدة طلبات/ثانية → إشغال كل الـworkers → الطابور يصل 9–30 ثانية، وهذا ما كان يُسقط طلب الريلز بـtimeout.

تم إصلاح كل ما يخصّ السيرفر والتحقق منه. يتبقّى تطبيق قواعد Cloudflare (تحتاج لوحتك) لإيقاف الزحف عند الحافة نهائياً.

③ بخصوص الريلز 🎬

الـbackend سليم 100%: الـfeed يرجع الفيديوهات بسرعة، روابط Bunny HLS تعمل (200)، وembed_url صحيح. اختفاء الفيديوهات كان عرَضاً للبطء (الطلب يفصل timeout بسبب إشغال الـworkers). مع التسريعات أعلاه + قواعد Cloudflare يُفترض أن يعود طبيعياً.

④ خطوات Cloudflare بالتفصيل

السبب الجذري لبطء الموقع هو الزحف على روابط الفلترة، وكل الطلبات تصل عبر نطاقات Cloudflare (172.x / 104.22.x / 162.158.x) فلا يكفي اللجم لكل IP من داخل السيرفر. الحل الدائم أن نوقف الزحف عند حافة Cloudflare قبل وصوله للسيرفر. طبّق القواعد الأربع التالية بالترتيب.
1

Rate Limiting على روابط /shop المفلترة الأهم

المسار في اللوحة: Security → WAF → Rate limiting rules → Create rule

اضغط Edit expression وألصق التعبير التالي في خانة When incoming requests match:

(starts_with(http.request.uri.path, "/shop") and
 (http.request.uri.query contains "attribute_value=" or
  http.request.uri.query contains "min_price=" or
  http.request.uri.query contains "max_price=" or
  http.request.uri.query contains "order=" or
  http.request.uri.query contains "view_mode=" or
  http.request.uri.query contains "hide_out_of_stock=" or
  http.request.uri.query contains "tags="))
  • Rate: 20 requests per 1 minute
  • With the same characteristics: IP (أو cf.unique_visitor_id إن ظهر لديك)
  • Then take action: Block لمدة 1 minute  (أو Managed Challenge إن أردت رفقاً أكبر بالبشر)

هذا يوقف الزحف عند الحافة فلا يصل للـworkers إطلاقاً — ويكمّل لجم السيرفر الداخلي (40/دقيقة).

2

Bot Fight Mode سريع

المسار: Security → Bots

  • فعّل Bot Fight Mode (مجاني) — يتصدّى للزواحف الآلية المعروفة تلقائياً.
  • إن كنت على خطة Pro+ استخدم Super Bot Fight Mode واضبط: Definitely automated → Block و Likely automated → Managed Challenge.
3

WAF Custom Rule — تحدّي الزواحف المتنكّرة فعّال

المسار: Security → WAF → Custom rules → Create rule

التعبير:

(starts_with(http.request.uri.path, "/shop")
 and http.request.uri.query contains "attribute_value="
 and not cf.client.bot)
  • Action: Managed Challenge

يمرّر البشر بصمت ويوقف الـscrapers التي تزيّف الـUser-Agent لتبدو متصفحاً.

4

Cache Rule لصفحة /shop العامة تخفيف حِمل

المسار: Caching → Cache Rules → Create rule

التعبير (الصفحة الأساسية فقط بدون فلاتر):

http.request.uri.path eq "/shop"
 and not http.request.uri.query contains "="
  • Cache eligibility: Eligible for cache
  • Edge TTL: Override origin → 2 minutes
  • Browser TTL: Respect origin
⚠️ تنبيه مهم: لا تُفعّل الكاش أبداً على روابط فيها فلاتر، ولا على /shop/cart / /shop/checkout / /shop/payment / /my/* / صفحات الحساب — اقصر الكاش على المسارات العامة فقط حتى لا تُعرض بيانات مستخدم لآخر.

⑤ كيف تتأكّد أنها تعمل

  • في Cloudflare: Security → Events ستظهر طلبات الزحف وهي تُحجب (Block / Challenge) خلال دقائق.
  • على السيرفر: متوسط الحِمل (load) يهبط وعدد الطلبات في الطابور يقترب من الصفر.
  • في التطبيق: تاب الريلز يعرض الفيديوهات مباشرة دون انتظار.

1

أنشئ توكن مخصّص (دقيقتان)

المسار: My Profile → API Tokens → Create Token → Create Custom Token

Permissions — الحد الأدنى المطلوب فقط:

  • Zone → Zone WAF → Edit
  • Zone → Zone Settings → Edit  (لتفعيل Bot Fight Mode)
  • Zone → Cache Rules → Edit

Zone Resources: Include → Specific zone → اختر uellow.com فقط (لا تعطِ كل الـzones).

TTL (اختياري لكن مفضّل): حدّد تاريخ انتهاء قريب (مثلاً يومين) فيُلغى التوكن تلقائياً.

ثم Continue → Create Token وانسخ التوكن.

2

سلّم التوكن بأمان مهم

لا تلصق التوكن في المحادثة مباشرة. بدلاً من ذلك اكتب هذا السطر في الـprompt (الـ! يشغّله في جلستك، و-s يخفي ما تكتبه):

! read -s CF_TOKEN && echo "$CF_TOKEN" > /root/.cf_token && chmod 600 /root/.cf_token

فيُحفظ التوكن في ملف محمي أقرأه دون أن يظهر في المحادثة.

3

زوّدني بالـZone ID

تجده في صفحة الدومين داخل Cloudflare → Overview (العمود الأيمن، أسفل API). تقدر تكتبه عادي في المحادثة — فهو معرّف عام وليس سرّاً.
