Codemagic & Store Release Setup Guide
المعرّف com.uellow.vendors · المستودع uellowcom/uellow-vendor · 16/06/2026

1 · إعداد Codemagic

  1. المستودع uellowcom/uellow-vendor متصل بـ Codemagic، وكل push على فرع main يشغّل بناءً تلقائياً.
  2. افتح codemagic.io ← التطبيق uellow-vendor. سترى الآن workflowـين: “Vendor — Android (APK + AAB)” و“Vendor — iOS App Store”.
  3. أضِف مجموعتَي المتغيّرات أدناه من تبويب Environment variables (اكتب الاسم والقيمة، فعّل Secret، اكتب اسم المجموعة في خانة Group، ثم Add).
  4. للبناء: Start new build ← اختر الـ workflow ← Start build.
  5. بعد الانتهاء، نزّل الملفات من قسم Artifacts (الـ AAB / APK لأندرويد، الـ IPA لـ iOS).

مجموعة vendor_signing — لبناء Android

Variable nameالقيمة / ValueSecret

لتوليد قيمة UELLOW_KEYSTORE_BASE64 من ملف الـ keystore على الخادم:
base64 -w0 /root/secrets/<keystore>.jks

Variable nameالقيمة / ValueSecret

2 · النشر على Google Play (Android)

  1. ⚠️ المعرّف الآن com.uellow.vendors (كان com.uellow.uellow_vendor) — لذا هو تطبيق جديد على Play.
  2. Play Console ← Create app ← الاسم Uellow Vendor ← App ← مجاني.
  3. Production (أو Internal testing) ← Create new release ← ارفع ملف uellow-vendors-1.1.5.aab.
  4. فعّل Play App Signing. مفتاح الرفع لدينا (بصمة SHA-1: 8D:FB:03:70:24:A7:EA:25:B4:39:9E:27:50:84:C3:07:A9:7F:21:81).
  5. املأ Store listing (الأيقونة + اللقطات + الوصف أدناه) ← أرسل للمراجعة.

3 · النشر على Apple (iOS)

  1. developer.apple.com ← Certificates, Identifiers & Profiles ← Identifiers ← + ← App IDs ← سجّل com.uellow.vendors.
  2. App Store Connect ← Apps ← + New App ← اختر نفس المعرّف ← الاسم Uellow Vendor.
  3. انسخ Apple ID الرقمي من صفحة التطبيق (App Information) وأضِفه كمتغيّر APP_APPLE_ID في مجموعة appstore بـ Codemagic.
  4. في مشروع Firebase uellow-app ← أضِف تطبيق iOS بمعرّف com.uellow.vendors ← نزّل GoogleService-Info.plist ← ضعه في ios/Runner/ (وإلا يتعطّل عند الإقلاع).
  5. تأكّد من وجود تكامل App Store Connect باسم uellow_appstore في Codemagic (نفس مفتاح تطبيق العميل، الدور Admin/App Manager).
  6. شغّل workflow “Vendor — iOS App Store” ← سيبني IPA ويرفعه إلى TestFlight تلقائياً.
ترتيب الإلزام: تسجيل المعرّف على Apple → إنشاء التطبيق على App Store Connect (للحصول على APP_APPLE_ID) → إضافة GoogleService-Info.plist → تشغيل الـ workflow.
